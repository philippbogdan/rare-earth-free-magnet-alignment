# What was known before opening

The condition files describe each sample's process and measurement setup with outcome values removed. `MANIFEST.json` maps them to case IDs and records the original sealed outcome hashes and batch membership. The [validation record](../../docs/validation.md) explains which rule version preceded each opening and which exposures were excluded.

Current outcome excerpts were shortened for publication. Their file hashes therefore differ from the sealed hashes recorded here; the original sealed bytes are not included. Frozen prediction files remain unchanged.
