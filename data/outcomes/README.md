# Measurements that test the ceilings

These files contain published remanence ratios, remanence and texture measurements, with sample conditions, uncertainties and citations. Match a record's `id` to `case` in a score file to inspect its conversion interval and frozen ceiling.

Held-out, exposed and post-hoc comparisons use the same measurements but have different evidential status. The [validation record](../../docs/validation.md) keeps them separate. Some records cannot test alignment, and some materials contain rare-earth substitutions or the Nd-Fe-B reference; inspect the composition and score status before selecting a subset.
