# Published physical inputs

The `*_inputs.yaml` files supply structures, easy axes, magnetic properties, transformation relationships and processing prerequisites, grouped by material family. Every record carries its source and supporting excerpt. `universe_inputs.yaml` records which candidate phases and alignment routes are named in the selected literature.

`known_cases_*.yaml` contains the visible reference examples used for fidelity checks, including the Nd-Fe-B reference. These are outcome records, not unseen validation. The [data guide](../../docs/data.md) defines the evidence fields and conventions.
